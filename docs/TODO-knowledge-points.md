# 考点映射待办清单（T1-4 / P0-3）

> 本文件由 `scripts/export-unmapped-kp.mjs` **自动生成**，请勿手工编辑。
> 重新生成：`node scripts/export-unmapped-kp.mjs`

## 背景

题库 `exam-bank.json` 的 `knowledgePoints` 字段与 `data/{subject}/knowledge.json` 的
`chapters[].topics[].name` 无法一一对应，导致错题无法归因到具体知识点，
「学习路径推荐」拿不到复习条目。

## 三类成因

| 类型 | 说明 | 处理方式 |
| --- | --- | --- |
| 模块名 | 值等于某个 chapter.name（如「光学与原子物理」「反应原理」） | 粒度太粗，**需拆成具体 topic** |
| 元数据标签 | 「综合应用」「高频考点」「基础概念」等描述题目特征 | 本就不是知识点，**应从 knowledgePoints 移出** |
| 真实知识点未收录 | 确为知识点但 canonical 表里没有 | **在 thesaurus 的 aliases 里补映射** |
