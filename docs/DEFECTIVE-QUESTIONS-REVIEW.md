## 1. A 组：无正确选项 / 无错误选项（3 道）

### A1 · `PHY_2025_37`（物理·选择题）

- **实证**：题干「弹簧振子做简谐振动时，下列量不变的是？」，选项为 A 加速度 / B 位移 / C 回复力 / D 速度。
  四者均随时间周期性变化（`x = A cosωt`、`F = -kx`、`a = -ω²x`、`v = -Aω sinωt`），现行答案键 `B` 无依据；
  真正保持不变的振幅、周期、机械能未列入选项。现行解析已如实指出。
- **定夺选项**：
  1. 将 D 项改为「机械能」（或「振幅」），答案键调整为 D（或新增项）——**建议**：改动最小，考点（简谐振动不变量的辨析）不变；
  2. 改题干为「下列量中随时间周期性变化的是」并改多选题型；
  3. 维持现状——不推荐：学生按现行解析无法自洽。

### A2 · `PHY_2025_64`（物理·选择题）

- **实证**：题干「研究平抛运动实验中，下列操作错误的是？」，四选项（末端切线水平 / 每次同一位置释放 /
  坐标纸紧贴木板 / 斜槽不必光滑）**全部是正确操作**；「斜槽不必光滑」即教材原话，现行答案键 `D` 无依据。
- **定夺选项**：
  1. 把 D 项改为真正的错误操作（如「斜槽末端切线可以不水平」或「小球从不同位置释放」），键维持 D——**建议**；
  2. 改题干为「下列操作正确的是」并改多选题型；
  3. 维持现状——不推荐。

### A3 · `biology_2020_138`（生物·选择题）

- **实证**：题干「染色体结构变异不包括？」，选项缺失 / 重复 / 倒位 / 易位**四项全是**结构变异类型，
  无正确选项；现行答案键 `D`（易位）不成立。
- **定夺选项**：
  1. 题干改为「染色体结构变异**包括**？」，答案键调整为 D（或任一结构变异项）——**建议**；
  2. 将某一选项替换为非结构变异类型（如「基因突变」），键指向该项；
  3. 维持现状——不推荐。

  杂合子 1/2；现行答案键 `C`(1/4) 只是单一纯合基因型的频率，与遗传学原理冲突。现行解析已写明正确计算。

## 4. D 组：题设结论不成立（2 道，数学解答题）

### D1 · `MATH_2021_141`（数学·解答题）

- **实证**：题面要求「求证平面 AEC₁F ⊥ 平面 ABCD」（正方体棱长 2，E、F 为 BB₁、DD₁ 中点）。
  坐标验算：平面 AEC₁F 法向量 (1,1,-2)，底面法向量 (0,0,1)，**点积 -2 ≠ 0**，两平面并不垂直，
  题设结论不成立；原解析含「略。」未完成推导，现行解析已改为可核验的坐标计算过程并如实标注。
- **定夺选项**：
  1. 修改题设（调整 E、F 位置或棱长使垂直成立）后重出全题——**建议**：需数学教研核算新参数；
  2. 改结论为「求二面角 AEC₁F-ABCD 的余弦值」（按现坐标可解）——保留原图形、考点转为角的计算；
  3. 维持现状——不推荐：证明无法完成。

### D2 · `MATH_2025_181`（数学·解答题）

- **实证**：题面要求「求证 A₁C ⊥ AB₁」（正三棱柱，AB = AA₁ = 2）。坐标验算：A₁C = (1,√3,-2)、
  AB₁ = (2,0,2)，**点积 -2 ≠ 0**，垂直不成立；原解析含「修正：…需重新核算」。第 (2) 问二面角依赖此结论。
- **定夺选项**：
  1. 调整题设参数（如改侧棱长或底面边长）使 A₁C ⊥ AB₁ 成立后重出——**建议**：需数学教研核算；
  2. 将 (1) 改「求证 A₁C 与 AB₁ 不垂直并求夹角」一类与现坐标自洽的设问；
  3. 维持现状——不推荐。

## 5. E 组：文本解读定性存疑（1 题 2 问）

### E1 · `CHN_2018_26`（语文·选择题）

- **实证**：文本写木棉花「开得热烈而决绝」，问「对这段文字赏析**不正确**的一项」，现行答案键 `D`
  （「全段语言风格清冷含蓄」为不正确项）。现行解读把「决绝」定性为刚烈、昂扬（毫无保留、义无反顾）。
  **存疑点**：「决绝」本义含「断绝、狠决」的消极色彩，其在现代散文中的情感定性存在解读分歧——
  若取消极解读，「热烈而决绝」的基调判断需重新斟酌，D 项「不正确」的定位随之动摇。
- **定夺选项**：
  1. 维持积极解读（主流文学解读：拟人化写生命张力），在解析中补注「决绝」的多义性以消歧——**建议**：答案键不动，仅补解析；
  2. 教研改取消极定性并重设选项；
  3. 维持现状且不补注——不推荐：歧义留给学生。

### E2 · `CHN_2018_27`（语文·解答题）

- **实证**：同文本炼字题「『决绝』一词有何表达效果？」，现行答案键与 E1 同取积极解读
  （毫无保留、义无反顾的生命张力）。
- **定夺选项**：与 E1 绑定定夺——若 E1 维持积极解读则本题无需改动；若改取消极定性，本题答案须同步重写。

## 6. F 组：数据规范缺陷（2 处，答案键本身无误）

### F1 · `CHN_2019_30`（语文·选择题）

- **实证**：病句辨析题，现行答案键 `C`（「世界杯期间，不少球迷熬夜看球，导致第二天上班精神不振。」）
  **经复核正确**（A「水平有了很大的改进」搭配不当、B「防止…不再发生」否定不当、D「将在今年建成并投入使用**了**」
  时态矛盾，三项均病句）。但解析写「B 否定不当；**C** 搭配不当，水平应提高；D 时态矛盾」——
  「水平应提高」描述的是 **A 项**错因，字母错标一位。`git show HEAD` 与工作树一致，为原始数据自带。
- **定夺选项**：
  1. 仅修订解析字母：「A 搭配不当，水平应提高；B 否定不当；D 时态矛盾」——**建议**：答案键不动，低风险；
  2. 维持现状——不推荐：解析与答案键字母矛盾会直接误导学生。

### F2 · 64 题 256 个选项自带字母前缀（语文 63 + 物理 1，系统性）

- **实证**：`options` 数组文本以「A. 」「B. 」开头（如 `CHN_2018_101` 选项 A =「A.乃重修岳阳楼 修：修建」；
  物理侧为 `PHY_2020_03`）。各渲染入口统一前置字母（`String.fromCharCode(65 + i) + '. ' + opt`，
  见 `app-biology.js` / `exam-review-system.js` / `app-chemistry.js` 等十余处），学生端显示为「A. A.xxx」。
  实测分布：**64 题 / 256 个选项**（语文 63 题 252 个 + 物理 1 题 4 个），集中在文言对比阅读与实词释义题。
- **定夺选项**：
  1. **渲染层剥离**（统一在字母前置处去除选项自带的 `^[A-D][.、．]\s*` 前缀）——**建议**：一处改动覆盖全部
     渲染入口，需做显示回归（确认无选项内容本身以字母加点开头的误伤，如实词释义「A.甲：甲物」形态需评估）；
  2. 数据层去前缀（256 处内容改动）——干净但改动面大，且须防与录入规范冲突；
  3. 维持现状——不推荐：全部受影响题目显示重复前缀。

## 7. 定夺与修改流程

1. 教研按本清单逐条定夺（可在「定夺选项」中打勾或填写其他处置）；
2. 定夺后的数据修改须保证**题面、选项、答案键、解析四者自洽**，由人工完成并按学科拆分提交；
3. 每次修改后跑 `npm run verify`（九阶段门禁）+ 对应题的渲染抽检；
4. **禁止**用脚本批量改写 `answer` 字段或题目内容（项目铁律，见 `docs/DEV-PLAN.md` T3-5 撰写规范）；
5. 全部定夺完成后，本清单状态列改为「已定夺」并归档结论至 `docs/ERRATA-REPORT.md`。
