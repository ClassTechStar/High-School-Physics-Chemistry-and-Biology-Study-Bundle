## 0. 什么叫这个项目的「AI 味」

不是"用了 AI 写的"，而是**机器生成物留下的可识别痕迹**。本项目里归纳为四类，每类都可机械检测：

| 类别 | 特征 | 检测方式 |
| --- | --- | --- |
| **A 装饰性 emoji** | 标题、列表项、功能性说明里的 emoji 堆砌 | 标题正则计数 |
| **B 营销腔套话** | 「一站式 / 打造 / 赋能 / 精准提分 / 智能备考 / 助力 / 全方位」 | 词表扫描 |
| **C 假宣称** | 宣称了代码里**并不存在**的功能或数字 | 逐条对照实现 |
| **D 机器模板内容** | 批量生成的结构化壳 + 填空式话术 | 多变体正则 |

**保留**：学生界面里作为**功能图标**的 emoji（工具卡图标、学科图标、反馈标记）——那是视觉设计，不是文案。判据是"它承载信息"还是"它只是装饰"。

## 2. 题库内容治理

### 2.1 四种机器模板，全部清零

| 模板 | 形态 | 命中 | 处理 |
| --- | --- | --- | --- |
| ① 「分析：题干。正确答案为X，相关知识点涉及Y。」 | 复述题干 + 报答案 + 空泛套话 | 102 | 逐题重写 |
| ② 「【考点】…【题干】…【概念】…【判断】…【结论】选X」 | 标签壳 + 填空式排除（「不符合上述概念或题干限定」逐字复用数百次） | 446 | 逐题重写 |
| ③ 「…，正确答案为X（内容）。本题考查…需准确理解…由…的基本原理可判断」 | 前半句有信息，后半截是批量空话 | 95 | 逐题重写 |
| ④ 「【考点】…【审题】…【答题思路】…【参考表述】…【评分关注】」等短标签变体 | 答题思路与评分关注是全库同一句套话 | 116 | 逐题重写 |

合计 **759 道题**的解析由机器壳换成了真正的讲解。

> **但这不等于清零。** 门禁 C11 的判据是「`【】`标签壳 **且** 填空式排除话术」或
> 「半句带答案内容 **且** 空话尾巴」，第一轮结束后它仍命中 **173 道**（化学 32 / 生物 141）。
> 原因是这 173 道的形态与上表四种略有差异——它们用的是
> `【考点】/【题干】/【概念】/【判断】/【结论】` 五段式，排除话术统一写成
> 「A 项「X」不符合上述概念或题干限定」，第一轮的四类正则没有覆盖到这一族。
> 补写情况见 2.4 节。

### 2.2 改写标准

- **不复述题干**
- **每个错项都要给出具体错因**（原模板一律写「不符合上述概念或题干限定」）
- 保留原解析里有价值的概念说明，融进自然段
- 不写「正确答案为X / 故选X」这种只报答案的结尾（避免与 `answer` 字段冲突，也避免退化成报答案）
- 禁止套话、禁止 emoji、最多两段

### 2.5 收尾扫描（分号罗列式解析判定 + 两处原始数据缺陷）

清理收尾对全库 1301 题做「分号罗列式」紧凑解析扫描，命中 9 道，逐条人工判定：

| 判定 | 题目 | 依据 |
| --- | --- | --- |
| **合法精简讲解** | `CHEM_2025_01` / `CHEM_2025_05` / `CHEM_2025_06` / `CHEM_2025_24` / `CHEM_2025_25` / `CHEM_2026_26` / `BIO_2023_13` | 每条都给出**具体错因或知识点**——「氦是单原子分子，He」「铜离子 Cu²⁺」「氯化铁 FeCl₃」「强酸弱碱盐，水解呈酸性」「-OH 连在饱和碳上属醇」，与机器壳的「不符合上述概念或题干限定」空话有本质区别，不构成 AI 味，**未重写** |
| 解析正确，未展开 D 项 | `CHN_2018_195` | 「C 无歧义、A/B 有歧义」判定正确；D「咬死了猎人的狗」的歧义未解释，属不完整而非错误 |

同时查出两处**原始数据缺陷**（均非 AI 味、均非本轮引入，按约定只标注不改动）：

**缺陷 A：`CHN_2019_30` 解析字母错标**

- 答案键 **C**（「世界杯期间，不少球迷熬夜看球，导致第二天上班精神不振。」）经复核**正确**——A「水平有了很大的**改进**」搭配不当、B「防止…**不再**发生」否定不当、D「将在今年建成并投入使用**了**」时态矛盾，三项均为病句，只有 C 无语病。
- 但解析写的是「B否定不当；**C**搭配不当，水平应提高；D时态矛盾。」——「水平应提高」描述的是 **A 项**的错因，字母错标一位。正确写法应为「A搭配不当，水平应提高；B否定不当；D时态矛盾。」
- `git show HEAD` 与工作树该字段一致，为原始数据自带；答案键无误，仅解析字母错标，未擅自改动。

**缺陷 B：64 题 256 个选项自带字母前缀（系统性）**

- 形态：`options` 数组文本以「A. 」「B. 」开头，如 `CHN_2018_101` 选项 A =「A.乃重修岳阳楼 修：修建」。
- 影响：各渲染入口统一前置字母（`String.fromCharCode(65 + i) + '. ' + opt`，见 `js/app-biology.js`、`js/exam-review-system.js`、`js/app-chemistry.js` 等十余处），学生端会显示成「A. A.乃重修岳阳楼 修：修建」。
- 分布：**语文 63 题 + 物理 1 题**（`PHY_2020_03`），共 256 个选项，集中在文言对比阅读与实词释义题。
- 属原始录入数据问题；修复涉及 256 处内容改动（数据层去前缀）或一处渲染层剥离，建议单独排期并做显示回归。
