核心功能（全部本地运行）

真题练习与错题归因

1198 道真题按学科 / 章节 / 难度 / 年份筛选；错题自动归因到考点，按复习优先级排序；分页加载保证千题级流畅浏览。

作息驱动的学习提醒

自定义每天的学习时段（支持单双周与假期覆写），驱动「当前时段」卡片与到点提醒——从「该学什么」到「现在该学什么」。

本地通知中心

打卡提醒、错题积压预警、时段开始提醒；Provider 注册表 + 频控去重，每类可独立开关，PWA 安装后支持系统通知。

可插拔轻插件

一份 JSON 清单 + 一个脚本即可注册通知 / 仪表盘卡片；apiVersion 版本门槛 + 超时隔离 + 连续失败自动停载，安全模式一键跳过。

外观主题包

护眼纸色 / 液态玻璃两套主题（含背景折射增强），加载失败自动回退；明暗双主题全站令牌驱动。

备份快照与锁定模式

每日自动 3 槽位快照可一键恢复；机房公共设备可设 PIN 隐藏清数据入口，防误触不加密。

工程与质量（评委可复现验证）

十阶段自动门禁

  1. 数据与题库结构质检
  2. 跨文件声明碰撞扫描
  3. CSP 内联事件 / 样式门禁
  4. 主题令牌一致性
  5. 作息数据校验
  6. 代码卫生（裸存储 / 转义覆盖）
  7. 内容语义（解析与答案矛盾检出）
  8. defer 时序运行时复现
  9. 存储与引擎单测（104 项）
  10. 功能冒烟（68 项）

安全与隐私设计

  • CSP：script-src 'self'、无内联事件、无内联样式，object-src 'none'
  • 全部交互经声明式委托（data-call / data-hook），样式经 CSSOM 桥
  • 备份导入按 schema 白名单净化，防原型污染与超长载荷
  • 学习记录仅存浏览器本地，不收集、不上报、无第三方请求
  • 门禁自举：CI 内注入已知缺陷，验证门禁自身具备真实失败能力

体验工程

  • PWA 离线安装，Service Worker 分层预缓存（壳 22 项 / 其余空闲补齐）
  • 题库惰性加载与分页，首屏不拉取 1MB 题库
  • 全局 1Hz tick 心跳统一计时器；启动自检 + 安全模式自愈
  • Web Speech 朗读、深链路由（?goto=）、锁定模式

三分钟体验路线

  1. 打开 应用首页，点「🎲 随机挑战一题」立即作答；
  2. 错题自动归因，进入「提分工具 → 学习仪表盘」查看统计与迷你组件；
  3. 右下角 ⚙️ 设置 → 通用 → 外观主题包切换「液态玻璃」；
  4. 设置 → 作息表，启用示例作息后仪表盘出现「当前时段」；
  5. 断网刷新页面——PWA 离线依旧可用。
